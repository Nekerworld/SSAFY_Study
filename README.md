# SSAFY_Study

이 저장소는 SSAFY 과정 중 스터디 그룹에서 학습한 내용을 정리해 둔 공간입니다.  
컴퓨터 공학 기초부터 다양한 프로그래밍 언어 실습, 자료구조, 참고 학습 자료까지 포함하고 있습니다.

## 폴더 소개

### 1. CS
CS 관련 강의 자료와 기타 학습 자료가 들어 있습니다.  
주차별 강의 내용과 공부에 도움이 되는 자료를 정리해 두었습니다.
(260811 현재 딥러닝 스터디를 위해 잠시 일시정지된 상태입니다.)

### 2. 자료구조
자료구조 개념을 학습하기 위한 강의 자료와 코드 예제가 포함되어 있습니다.  
리스트, 집합, 성능 비교와 같은 기본 내용을 연습하는 데 활용할 수 있습니다.

### 3. Hello_World
여러 프로그래밍 언어로 작성한 Hello World 예제를 모아둔 폴더입니다.  
Python, C, C++, JavaScript, TypeScript, Java, Kotlin, Dart 등 다른 언어로는 헬로월드 이렇게 쓰는구나~ 하시면 됩니다.

### 4. 참고 자료
컴퓨터 구조, 데이터구조, 네트워크, 머신러닝, 딥러닝, 자연어처리 등 다양한 주제의 참고 자료를 모아둔 폴더입니다.  
각 분야의 핵심 개념을 복습하고 정리하는 데 유용합니다.
대학 시절 수업받은 강의자료들을 올려놨습니다.

## 이 저장소의 목적
- 학습한 내용을 체계적으로 정리하기 위함
- 복습과 재참조를 쉽게 하기 위함
- 다양한 주제를 한곳에서 관리하기 위함
- 비전공자 및 입문자들에게 조금이라도 도움이 되기 위함
