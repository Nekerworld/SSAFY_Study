# 키워드 (참고용)

### 데이터구조론
* 키워드: **Array, Linked List, Stack, Queue, Tree, Graph, Sorting, C 구현**
* 01장 — 강의 목적·학습 범위와 자료구조 기초 개념(추상 자료형, 복잡도) 정리.
* 02장 — 알고리즘 설계 기본과 자료구조 선택 기준(시간·공간 복잡도) 설명.
* 03장 — C언어로의 자료구조 구현 패턴(포인터, 메모리 관리) 예시 중심.
* 04장 — 배열·선형리스트의 구현·연산·복잡도 비교.
* 05장 — 단일·이중·원형 연결리스트 구조와 삽입/삭제 알고리즘, 응용.
* 07장 — 스택 개념, 표현, 재귀/표현식 처리 응용(후위표기 등).
* 08장 — 큐·원형큐·디큐 구현과 운영 사례.
* 09장 — 이진트리, 순회, 트리 응용(표현·검색) 정리.
* 11, 12, 13장 — 그래프 표현(인접행렬/리스트), BFS/DFS, 최단경로/탐색 기본.
* 14장 — 기본 정렬(버블/선택/삽입)과 합병/퀵/힙 정렬의 원리 및 복잡도.

### 컴퓨터구조론
* 키워드: **CPU, 명령어집합, 데이터경로, 제어, Cache, 파이프라인, 메모리 구조(DRAM/SRAM)**

* 4장 - 제어유닛 설계(하드·마이크로프로그램) 개념과 제어 신호 흐름.

* 7장 - 캐시 메모리 원리(지역성), 블록매핑·교체정책 소개.
* 8장 - 캐시 계층과 메모리 일관성 문제, 성능 분석 관점.

* 딥러닝과 강화학습 기초 — 딥러닝 기본 개념과 강화학습 개요, 간단한 예시.

* GAN - GAN의 생성자/판별자 구조와 학습 불안정성, 개선기법 개요.
* 트랜스포머 - 어텐션 메커니즘과 트랜스포머 구조(병렬 학습·Positional Encoding).
* 강화학습 - 강화학습의 기본(에이전트·환경·보상)과 간단한 알고리즘 소개.

### 네트워크
* 키워드: **OSI/TCP‑IP, 물리층, 디지털/아날로그 전송, 다중화, 전송매체, 스위칭·교환, 데이터링크(MAC), 오류검출/정정, 이더넷, 무선 LAN**
* 개요 - 네트워크 기본 개념(호스트·라우터·프로토콜)과 학습 목표.
* 네트워크 모델 - OSI/TCP‑IP 계층 모델 비교·역할 정리.
* 물리층개요 - 물리층 신호·전송 매체(유선/무선) 기본.
* 디지털전송 - 디지털 신호 전송·인코딩 방식·에러 영향.
* 아날로그 전송 - 아날로그 전송 기초·대역폭·잡음 영향.
* 대역폭 활용-다중화와 대역확산 - 다중화(시분할·주파수)와 확산 스펙트럼 개념.
* 전송매체 - 케이블·광섬유·무선 매체 특성 비교.
* 교환 - 회선교환·패킷교환·스위칭 원리 및 장단점.
* 데이터링크층 개요 - 데이터링크 역할·프레이밍·MAC 개념.
* 오류 검출과 오류 정정 - 패리티·CRC 등 오류검출 및 ARQ 등 정정기법.
* 데이터 링크 제어 - 흐름제어·에러제어 프로토콜(슬라이딩 윈도우 등).
* 매체 접근 제어(MAC) - CSMA/CD, CSMA/CA 등 MAC 프로토콜 비교.
* 유선 LAN-이더넷 - 이더넷 표준·프레임 형식·스위치 동작.
* 무선 LAN - 802.11 무선 LAN 구조, MAC/PHY 특성 및 보안 이슈.

### Imbalance & Anomaly Detection
* 키워드: **데이터 불균형, Oversampling, Undersampling, 이상탐지, 평가 지표**
* Introduction of Machine Learning — ML 기초와 문제 정의.
* Data Imbalance problem - undersampling — 불균형 문제 개요와 언더샘플링 기법(단점 포함).
* Data Imbalance problem - oversampling — 오버샘플링 방법과 주의점.
* Anomaly detection I & II — 이상탐지 기법(통계적·거리 기반·밀도 기반·모델 기반), 실무 적용과 평가, 예제 해설(이상치 정의·탐지 파이프라인).
